# BoothNest 已购同步扩展

每天读取一次已登录 BOOTH 下载库的商品清单，直接同步到本机 GUI；支持 Chrome / Edge。不会下载素材文件，也不读取、导出 Cookie、密码或订单信息。首次配对会立即同步；扩展弹出页还可手动同步。

1. 解压从 BoothNest 下载的 ZIP，保留全部文件。
2. 在登录 BOOTH 的普通浏览器打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式，选择「加载解压缩的扩展」，选中包含 manifest.json 的文件夹。
3. 在 GUI「数据管理 → 已购自动同步」生成并复制配对信息，点击浏览器工具栏中的此扩展，粘贴配对。
4. 浏览器与 GUI 运行时，距上次尝试达到 24 小时就同步；下次同时可用时补做过期任务。GUI 可暂停、请求立即同步或解除配对。

同步时会创建一个临时的后台下载库标签页，完成或失败后自动关闭，只关闭扩展自己创建的标签页。登录失效、网页验证、页面变化或 GUI 离线时显示原因；在普通浏览器处理后点击「立即同步」。浏览器被关闭时不会唤醒电脑或启动 GUI。

配对凭据保存在扩展本机存储中，接收端只接受配对扩展。配对信息 10 分钟后失效，且只能使用一次。卸载扩展前可在 GUI 解除配对。扩展不会识别 BOOTH 账号身份；切换账号时请先解除配对，使用单独的 BoothNest 数据目录以免合并不同账号。
