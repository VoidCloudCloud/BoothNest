# Qt 客户端第三方组件

许可原文见 `licenses/Qt-LGPL-3.0.txt`、`licenses/Qt-GPL-2.0.txt` 和应用根目录 `LICENSE`（GPLv3）。随 wheel 附带的商业授权说明也一并保留，开源使用不依赖购买商业授权。Qt/PySide 动态库未修改，保留为可替换的独立文件。

项目与源代码：https://code.qt.io/pyside/pyside-setup.git/ 。Qt 源码与许可：https://www.qt.io/qt-licensing 、https://code.qt.io/qt/qtbase.git/ 。构建时使用的版本固定于 `requirements-qt.txt`。

Python、Node.js、PyInstaller、VRCatalogue Open Data 等既有组件的声明见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。此 Qt 客户端无需系统 Edge / Chrome；BOOTH 登录与浏览器扩展仍在用户自己的浏览器中完成。
