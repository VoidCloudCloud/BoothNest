# 可选开放元数据

本次基础网站发行不包含、不更新、也不自动下载 VRCatalogue 数据库或其他商品数据。没有该索引时，网站继续使用自身已有目录，搜索和筛选按现有记录工作；数据管理显示索引未安装。

为兼容用户自行保留的可选索引，读取接口仍接受 `BOOTH_NEST_OPEN_DATA` 指定的绝对文件路径，或网站目录下 `resources/vrcatalogue.sqlite`。读取层只读，不把分类、模型适配或标签补充结果回写到原始商品目录。单独更新网站代码时无需替换已有索引。

如果自行取得 VRCatalogue Open Data，请先核对 https://huggingface.co/datasets/vrcatalogue/vrcatalogue-open-data 的许可并保留来源、作者 VRCatalogue、CC BY 4.0 许可链接及修改说明。上游开放元数据不包含商品标题、描述或图片，不能用其许可作为这些素材的再分发依据。

基础网站无需安装此索引即可运行；本次发行包也没有附带数据转换或下载任务。测试中的数据库仅为运行时生成的少量合成记录，不是上游数据副本。
