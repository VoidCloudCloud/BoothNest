# 网站更新记录

## 未发布 — 2026-11-06

- 新增排除标签、最多 50 组保存筛选、最多 500 件最近浏览和 Ctrl+K / ⌘K 快速查找；查找覆盖已收录商品、模型、创作者和标签。
- 包含标签采用全部匹配，排除标签采用任一匹配；最近浏览遵循打开顺序并继续应用筛选。
- 缩短卡片摘要、按需布局并合并筛选统计，减少搜索与翻页时的界面停顿；搜索兼容中文输入法组合输入。
- 界面偏好按字段合并并依次保存，避免收藏、最近浏览与保存筛选的并发更新互相覆盖。
- 同步自动识别对带点号目录、Unicode 文字和完整短标题的改进，保留同名歧义保护与多层目录回归。
- 支持自行配置的公开预览图索引和缓存，限制外部图片来源与并发；源码包不含索引、图片或个人数据。

## 2.0.0-beta.7 — 2026-11-04

- 修复 [#1](https://github.com/VoidCloudCloud/BoothNest/issues/1)：内置扫描引擎将收纳目录中的两个不同 ID 商品分别建档，扫描上级目录也保留独立的商品和大小。
- 区分独立商品与重复同一 ID 的配套文件，不因一个文件名含多个 ID 就展开整个目录。
- 补充网站 API 的真实引擎回归，核对扫描子目录 / 上级目录的商品、大小和原文件内容一致。
- 程序更新不自动重扫；已合并的旧快照需用户主动刷新。数据目录、人工规则和缓存继续保留。

## 2.0.0-beta.6 — 2026-11-04

- 修复在线模式轮询桌面扩展状态时反复返回 409：登录后返回“不支持 / 未启用”的只读状态；配对与同步写操作继续禁用。
- 区分浏览器 GUI、新版网站源码包与原 Windows 桌面 EXE，提供直接下载入口和运行环境说明。
- 补充现有网站数据、BoothNest / BoothShelf 库存及 `bytes` / `size` 字段的兼容范围、路径设置与升级步骤。
- 沿用只含程序的发行方式，不附数据、数据库、图片缓存或账户配置；不更新 Windows 桌面包。

## 2.0.0-beta.5 — 2026-11-02

- 首次单独发布 BoothNest 基础网站源码，支持新版浏览、筛选、收藏、详情与原有库存管理。
- 提供带登录验证的在线入口、Docker 配置模板和空库启动方式。
- 程序与数据分离：不附商品目录、开放数据库、预览缓存、个人库存或购买记录；启动不注入种子商品。
- 保留可选索引读取兼容性；更新网站无需更新已有数据。
- 独立的网站测试与源码打包流程；原 Windows 桌面 Beta 3 发布保持可用。
