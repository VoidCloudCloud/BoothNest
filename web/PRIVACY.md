# 数据与隐私

基础网站发行包只提供程序代码，不携带商品目录、开放元数据库、商品图片、个人库存、购买记录、登录凭据、浏览器配置或开发机缓存。

本机入口 `server.mjs` 只监听回环地址；`online.mjs` 为服务器入口，使用管理员设置的 HTTP Basic 登录和 Host/Origin 检查。公网部署应使用 HTTPS 反向代理。网页数据默认放在 `data/`，可用 `BOOTH_NEST_WEB_HOME` 指定独立路径；原扫描引擎的数据目录由 `BOOTH_NEST_ENGINE_HOME` 指定。请勿将运行数据目录提交到 Git 或作为发行附件。

扫描只读取下载素材，识别规则、统计、缓存和导出保存在独立的数据目录。程序不移动、删除、执行下载文件，也不自动更新它们的内容。首次启动空库，不自动收录商品。用户启用联网扫描、公开目录同步或 BOOTH 导入后，才会向 BOOTH 发送商品 ID/搜索关键词并请求商品资料和图片；已有定时任务按原配置运行。没有遥测、广告或向开发者服务器上传库存的功能。

购买记录由用户主动导入，或在本机入口中通过自选、配对的扩展传入。扩展不读取 Cookie API，不传输密码或订单信息；在线服务器入口不接受桌面扩展配对与同步。配对状态、令牌、购买记录、收藏、原始导出和日志应作为私有数据保存。

收藏、保存的筛选条件与最近浏览商品保存在服务数据目录的 `web-preferences.json`，使用同一实例的访问者共享这些偏好。最近浏览最多保留 500 件商品，可在界面移除或清空；快速查找只搜索该实例已收录的内容。保存筛选和页面地址不包含本地路径、配对凭据或收藏 / 最近浏览的具体商品 ID；其中的视图条件仍指向当前实例的数据。

可选元数据索引仅在本地只读查询，本次发行不包含或自动下载该索引。安装者自行提供索引时，应保留相应来源与许可。更新程序文件不替换已有商品目录、库存或缓存。

可选公开预览图索引同样由安装者自行提供，程序按商品 ID 读取，不改写商品目录或个人记录。启用后会向允许的 BOOTH 图床请求图片并在该实例的数据目录缓存，不发送 BOOTH 登录凭据；离线模式只使用已有本地图。
